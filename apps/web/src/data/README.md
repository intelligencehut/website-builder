# Data Directory

This directory contains static data files and mock data for development.

## Structure

- `programs.json` - Program data
- `testimonials.json` - Testimonial data  
- `team.json` - Team member data
- `news.json` - News articles
- `events.json` - Event data
- `gallery.json` - Gallery images metadata

## Usage

These files serve as mock data during development and can be replaced with CMS or API data in production.
