# Section Components

This directory contains page section components for the website.

## Components

- `Hero.tsx` - Hero/banner section
- `About.tsx` - About/mission section
- `Programs.tsx` - Programs showcase
- `Impact.tsx` - Impact metrics and stories
- `Gallery.tsx` - Photo gallery
- `News.tsx` - News and updates
- `Contact.tsx` - Contact section
- `Testimonials.tsx` - Testimonials carousel
- `Footer.tsx` - Site footer

## Structure

Each section component should be self-contained and follow the established design patterns.
